# AGENTS.md — общие правила репозитория

Действуют для **всех** агентов (Claude, Qwen) и для любого автоматизированного изменения.
Ролевые ограничения: [CLAUDE.md](CLAUDE.md), [QWEN.md](QWEN.md).

## 1. Сохранение пользовательских изменений
- Перед работой проверять `git status --short`. Грязное дерево с чужими правками — стоп и эскалация.
- Не откатывать, не перезаписывать и не «чистить» изменения, которых нет в своём scope.
- Запрещены `git stash` (стек общий между worktrees), `reset --hard`, `checkout -- .`, `clean -fd`, `push --force`.
- Установка новых файлов поверх существующих — только после чтения текущего содержимого.

## 2. Секреты
- Никаких токенов, паролей, ключей, cloudId-производных учётных данных в коде, тестах, логах, комментариях и commit-сообщениях.
- Никаких абсолютных путей пользователя (домашние каталоги, пути worktree) в файлах репозитория — только пути относительно корня репозитория.
- Секреты передаются только через окружение и никогда не логируются.

## 3. Минимальный diff
- Менять ровно то, что требует задача. Никакого попутного рефакторинга, переформатирования и переименований.
- Не менять стиль и структуру файлов, которых не касается задача.

## 4. Тесты обязательны
- Любое изменение поведения сопровождается тестом в `test/**` на `node:test`.
- `node --test` должен быть зелёным до commit. Красные тесты не коммитятся.
- Гейты качества: [docs/architecture/quality-gates.md](docs/architecture/quality-gates.md).

## 5. Публичный API
- Публичный API (экспорты `src/**`) не меняется без явного указания в ТЗ.
- Совместимость и границы: [docs/architecture/boundaries.md](docs/architecture/boundaries.md).

## 6. Зависимости
- Внешние runtime-зависимости не добавляются. Репозиторий работает на стандартной библиотеке Node.js 22.
- Исключение — явное разрешение в ТЗ с обоснованием.
