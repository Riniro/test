# Архитектура: текущее состояние

Документ описывает **фактическое** состояние репозитория. Гипотетические компоненты сюда не добавляются.

## Тип проекта
ESM-пакет Node.js (`"type": "module"` в `package.json`), приватный, без сборки и без runtime-зависимостей.
Целевая среда — Node.js 22.

## Состав
```
package.json          имя senior-claude, private, type=module, script "test": "node --test"
README.md
src/duration.js       единственный модуль исходного кода
test/duration.test.js единственный тестовый файл
```

## src/duration.js
Экспортирует одну чистую функцию `parseDuration(input: string): number` — парсит строку длительности
(`"1h 30m"`, `"1h30m"`, `"1d 2h 3m 4s 5ms"`) и возвращает число миллисекунд.

- Поддерживаемые единицы: `ms`, `s`, `m`, `h`, `d`.
- Части складываются; порядок и повторы единиц допустимы.
- Побочных эффектов, I/O и глобального состояния нет.
- Ошибки: `TypeError` — вход не строка; `RangeError` — пустая строка или нераспознанный формат.

## test/duration.test.js
Тесты на встроенном раннере `node:test` с `node:assert/strict`. Покрывают единицы, композитные строки,
ноль, повтор единиц, пробелы, а также оба класса ошибок. Внешний тест-фреймворк не используется.

## Зависимости
`dependencies` и `devDependencies` отсутствуют. Lint и typecheck в проекте не настроены.
