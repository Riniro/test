# Гейты качества

Единый источник истины по обязательным проверкам. Другие документы ссылаются сюда, а не копируют список.

## Обязательные команды
| Гейт | Команда | Условие прохождения |
|---|---|---|
| Тесты | `node --test` | Все тесты зелёные, ноль fail |
| Whitespace / конфликты | `git diff --check` | Пустой вывод |
| Чистота дерева | `git status --short` | Нет неотслеживаемых и незакоммиченных остатков после commit |

Lint и typecheck в проекте отсутствуют — подменять их «похожими» командами нельзя,
добавлять их в рамках продуктовой задачи тоже нельзя (только отдельным решением с ADR).

## Правила
- Гейты выполняет воркер **до** commit и повторно, независимо, Claude при ревью.
- Красные гейты → commit не делается, отправляется escalation (см. [../ai/recovery.md](../ai/recovery.md)).
- Каждое изменение поведения покрывается тестом на `node:test`; исправление бага начинается с падающего теста.
- Тест не считается покрытием, если он проходит и на старом коде.
- Диагностический вывод (`console.log`) не остаётся в `src/**` и `test/**`.

## Definition of Done для одной задачи воркера
1. Реализован ровно заявленный scope, ни файлом больше.
2. Все гейты выше зелёные.
3. Ровно один commit с сообщением из ТЗ.
4. `worker_done` отправлен один раз с `taskId` и `dispatchId`.
5. Ревью Claude по [../ai/review-checklist.md](../ai/review-checklist.md) дало `ACCEPT`.
